# Куда уходят ваши данные

Коротко: заметки лежат на вашем сервере, голос расшифровывается там же, а текст и то,
что агент читает в работе, уходит в Anthropic через вашу подписку Claude.

## Кто что видит

| Куда | Что уходит | Почему |
|------|------------|--------|
| **Telegram** | всё, что вы пишете и присылаете боту, и его ответы | бот работает через Telegram Bot API (`api.telegram.org`); переписка хранится у Telegram по его правилам |
| **Anthropic** (Claude) | текст сообщений, расшифровка голоса, фото и документы, которые агент открывает, и файлы vault, которые он читает в работе | мышление агента — сессия Claude Code на вашей подписке Pro/Max; действуют условия Anthropic для вашего тарифа |
| **Локальный Whisper** | аудио голосовых | faster-whisper на вашей машине (`WHISPER_URL`, по умолчанию `127.0.0.1`); аудио в облако не уходит |
| **Ваш git-ремоут** (форк на GitHub) | несекретная часть vault: `goals/`, профиль `about.md`, настройки агента | команда `/process` делает `git commit` и `git push` в ремоут текущей ветки — поэтому форк должен быть **приватным** |

Личные разделы vault в git не попадают — они в `.gitignore`: `daily/`, `contacts/`,
`finances/`, `attachments/`, `thoughts/`, `business/`, `projects/`. Они хранятся только на сервере.

Больше никуда: аналитики, телеметрии и сторонних API у бота нет.

## Где лежит на сервере

| Что | Где |
|-----|-----|
| Заметки, вложения, дневник | `vault/` в каталоге проекта (`VAULT_PATH`) |
| Ежедневные снимки vault | `~/.dbrain/backups/vault-ГГГГ-ММ-ДД.tgz`, хранятся 14 дней, на том же диске |
| Журнал панели Claude (текст диалога) | `~/.dbrain/pane.log` |
| Логи бота | `journalctl --user -u dbrain-bot` |
| Токены и ID | `.env` в каталоге проекта |

## Как удалить

```bash
systemctl --user disable --now dbrain-bot dbrain-watchdog dbrain-doctor.timer dbrain-process.timer
rm -rf ~/stack/agent-second-brain/vault ~/.dbrain      # заметки, снимки, журнал панели
journalctl --user --vacuum-time=1s                    # логи (чистит весь пользовательский журнал)
```

Вне сервера удаляется отдельно:

- **Telegram** — очистить чат с ботом и удалить бота у [@BotFather](https://t.me/BotFather) (`/deletebot`).
- **Anthropic** — история Claude Code живёт по правилам вашего аккаунта; локальные транскрипты — `~/.claude/projects/`.
- **GitHub** — удалить форк или вычистить `vault/` из его истории.
